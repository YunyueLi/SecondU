# Hither desktop

Hither is a working name. This is an independent local open-source project, not the private digital-twin repository.

- Use official `@openai/apps-sdk-ui` components and CSS directly. All screens, custom timeline/graph compositions, settings and component catalogue share those tokens. No alternative green/glass dashboard design.
- Only fictional, clearly labelled seed records belong in this repository. Never copy private records, keys, local logs or research media. Runtime data and credentials stay in `.hither/` and are never tracked.
- Keep source evidence, confirmed facts, inferences, corrections and task state distinct. Never fabricate model execution, successful actions or data provenance.
- Core modules own their state; preserve task/artefact histories and enforce workspace limits. Model output does not grant permission.
- Require real browser verification, meaningful persistence/runtime tests and source-based design review. Do not claim provider or native packaging validation until run.
- Preserve the documented Manus/Cue, Grok, Muse and OpenJarvis design references and the reasoning for adopting or declining a mechanism.

File ownership during initial parallel build: runtime agent `server/` and backend tests; interface agent `src/` except `src/cognition/`; cognition agent `src/cognition/`; root `shared/`, root config, docs, desktop packaging and integration. Coordinate contract changes before editing shared types.
