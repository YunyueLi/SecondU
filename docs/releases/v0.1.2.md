# SecondU v0.1.2

This release brings existing personal context into a reviewable workflow and rebuilds the bilingual website around the actual application.

- Review imported memory, edit individual candidates, confirm selected items and carry context into an unsent task draft. JSON and Markdown exports retain evidence and revisions.
- Share an explicitly authorized, revocable context snapshot through the local read-only MCP interface. This does not grant task execution or access to every personal record.
- Use one setup flow for a catalogue of 13 messaging platforms, with platform capabilities and account authorization kept explicit.
- Explore authored Chinese and English career discussions with editable comparison outlines. These fictional examples do not represent live model runs.
- Work in the website's actual product interface, with temporary imports, editable results and demonstrations that pause on interaction. Page-local changes clear on reload.
- Use fully collapsible native macOS navigation, fullscreen and revised mobile controls. The public repository also includes the initial 12-call synthetic context comparison, without a broad model-quality claim.

The archive supports **Apple silicon Macs running macOS 13 or newer**. It is ad-hoc signed and has not been Apple-notarized. Verify it with `SHA256SUMS.txt`. Real tasks require a configured model connection and authorized tools; fictional examples stay separate from personal data. See [Quick start](../../QUICKSTART.md) and [Context benchmark](../CONTEXT-BENCHMARK.md).
