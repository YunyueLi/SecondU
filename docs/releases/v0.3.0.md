# SecondU v0.3.0

2026 年 11 月 5 日 · Apple Silicon Mac · macOS 13 或更新版本

## 本次更新

1. **安装与模型连接。** 桌面应用内置 Codex CLI 0.165.0、配套程序与许可证，随应用整体升级。配置自己的模型连接即可开始真实任务，无需再装 Codex App、CLI 或 Node.js。组件缺失或版本不符时明确报错，不借用其他应用的组件。
2. **专家与团队。** 从选择专家、描述目标与材料开始。负责人追问缺失信息、提出分工与交付要求；可修改、拒绝或确认，确认后才派工。各成员可用不同模型，按实际依赖顺序或并行工作，下游成员收到上游生成的文件，负责人读取成果定稿。
3. **流程保存、复用与恢复。** 保存分工、模型与参数定义，下次用新材料重新确认，不夹带旧文件或结论。流程脚本支持循环、条件、并行和传递结果。中断后可续跑原任务，保留已完成的分工和文件；输入、配置或成果变化时不会静默复用。
4. **协作记录、聊天与交付。** 按轮次进入协作记录，查看阶段依赖、成员真实回复、工具调用、输入和交付文件。流程在宽屏横排、窄侧栏纵排。区分等待补充、未开始、失败与停止。修正澄清时误报失败、负责人定稿未归入成果、短消息气泡过宽等问题；查看文件再返回保留草稿和滚动位置。
5. **专业能力与 Office。** 整合标准能力包、专家技能及工具绑定，以及本地 Word、Excel、PowerPoint 生成、检查、渲染和 PDF 导出工具。保留第三方来源与许可。此前撤回的配置式专家界面保持关闭；完整自然语言创建、分发体验及跨场景模型质量不列为本版已验收功能。
6. **财务对话与多币种。** 财务附件改为紧凑快照，点开独立预览，可看账户、持仓、周报或测算，隐藏金额或下载原文件。总览按所选显示币种汇总全部账户及已记录负债；原币筛选只在明细生效。币种菜单加入旗帜，区分 CNY 和 CNH，缺少汇率时显示待折算。桌面首次进入示例即有完整虚构资产，与官网使用同一份带日期的数据，保留已有账目。
7. **首页与窄屏。** 首页只保留三条任务建议，距输入工具栏 12px，桌面基础行高 36px，窄屏点击高度 44px。去掉常驻连接模型提示和重复记忆入口，导入仍可从个人画像、设置与首次引导进入。长来源标题和模型名称按实际空间显示。统一财务、Agent、项目、自动化与会话的窄屏顶栏、控件、表单间距、菜单及弹窗返回焦点。
8. **macOS 桌面。** 统一弹窗顶部安全区与关闭操作；退出遇到未保存内容时可以返回保留草稿，或明确放弃草稿退出。保存、上传和运行中的任务仍受保护。
9. **官网、文档与资料边界。** 整合此前已上线的独立官网、交互示例、明暗主题与移动端改进。同步中英文 README、快速开始、应用引导与执行组件维护说明。产品源码、研究材料及私人数字分身资料分别维护；账户、凭据和本机日志不进入发行包。
10. **构建维护。** 新应用签名完毕后才替换输出；替换失败恢复原应用，成功后删除临时副本，不再为每次构建永久留下一份旧应用。

## English

SecondU now includes its own pinned execution runtime. Review a team's plan, choose member models, follow real file handoffs, continue interrupted runs, and reuse workflows with fresh materials. This release also improves conversations and deliverables, finance previews and currency handling, home suggestions and narrow layouts, macOS quit protection, and local Office tools. It incorporates the website refresh and updates the bilingual setup and product guides.
