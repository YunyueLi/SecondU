# SecondU v0.2.0

本版围绕「分身建设」，完善资料接入、个人理解与任务协作，并加入独立手机界面。

## 本版更新

- **七类材料入口。** 支持已有资料、文字与笔记、相册、聊天记录、已有记忆、连接资料和直接输入，沿用同一资料库。
- **保留原件。** 材料先保存为来源记录，再按需交给模型整理；没有连接模型时也可以先存下。
- **由你确认理解。** 模型生成的候选附带来源，可采用、修改或跳过；确认后的背景可以带入新任务草稿。材料也可选择仅用于本次任务。
- **逐步形成分身。** 双侧脸随资料接入与理解确认逐步变化，方便查看当前积累。
- **本机主动帮助。** 按资料变化发现相关事项并准备建议，默认关闭，可按空间开启。
- **手机与官网体验。** 新增手机导航、资料阅读和材料导入界面，官网同步提供分身建设演示。

## 下载与使用

[下载 macOS 版](https://github.com/YunyueLi/SecondU/releases/download/v0.2.0/SecondU-v0.2.0-macos-arm64.zip) · [安装说明](https://github.com/YunyueLi/SecondU/blob/main/QUICKSTART.md)

支持 Apple silicon（arm64）和 macOS 13 或更新版本。应用尚未经过 Apple 公证。

材料理解需要自行连接模型。手机界面使用电脑上的本机服务；视频目前支持保存与回看。
