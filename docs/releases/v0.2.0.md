# SecondU v0.2.0

本版围绕「分身建设」，把已有资料、模型整理、本人审阅与下一项任务接成可检查的产品流程，同时提供独立手机界面和同款官网展示。

## 本版变化

- **七项材料入口。** 从已有资料、文字与笔记、相册、聊天记录、已有记忆、连接资料及直接输入开始，沿用同一资料库；三维双侧脸随已有资料与已确认理解逐步形成。
- **先保存原件，再形成理解。** 文件与导入材料先落入来源记录，详情中可继续整理。直接输入可以选择「用于了解我」或「只用于这次」；没有配置模型时明确保留待处理状态。
- **本人审阅。** 模型候选附带来源，用户可采用、修改或跳过。确认后的背景可用于准备新任务草稿，处理失败保留原件与记录。
- **本机主动联系。** 默认关闭。开启后按来源变化筛选关联事项，先通过只读模型评估准备有依据的结果，再判断是否联系用户。运行中的事项结束后继续评估；已取消、失败或中断的事项停止评估与派送。
- **手机界面。** 提供移动导航、资料阅读、材料导入、任务工具和设置，复用桌面的本机服务与数据。
- **官网和文档。** 在首页原有三组展示后新增同款分身建设区，支持中英文、深浅主题、轮播暂停与手机入口；更新中英文 README、产品说明与应用内迭代记录。

## 使用范围

安装包适用于 Apple silicon（arm64）与 macOS 13 或更新版本。采用 ad-hoc 签名，未经 Apple 公证；应用内更新由 Sparkle 的 Ed25519 签名验证提供完整性保护。

材料理解需要自行连接模型。视频目前作为原件保存与回看；移动页面需要访问电脑上的服务。本版没有新增云同步、系统分享扩展、手机后台唤醒或持续摄像理解。主动评估要求本机服务运行，开关以当前空间为范围。

## 验证

- 最终本机全量测试 843 项：830 通过、13 项环境条件跳过、0 失败；类型检查与生产构建通过。
- 发布审查修复主动评估的两个状态问题，并通过实际 TaskRunner 完成及 HTTP 取消路径的回归测试。
- 原生隔离副本实际启动，保存一份仅本次使用的虚构材料，在未连接模型时准确显示待处理；正常退出并重启后，原文记录仍保留。没有执行模型请求，也没有改动用户现有数据。
- 包内 1,703 个文件通过禁止路径扫描；735 个应用、服务、共享代码及文档文件与对应构建输入匹配，严格签名检查通过。最终封包另保留资产摘要和签名验证回执。
- 官网实际检查了中英文、深浅色、390px 无横向溢出、七项手机材料入口、暂停与恢复。
- Kimi K3 max 视觉复核调用返回 HTTP 401，未取得审阅结论。上述浏览器检查与自动测试不冒充该项通过。

原生验收通过修改显示身份、bundle identifier 和用户数据目录隔离副本；该结果不等于已验证现有用户数据的原地升级。既有模型抽取证据属于此前各自运行范围，本次没有重跑真实模型。公开发布与官网下载回执将在发布后追加，冻结包不随文档回执修改。
