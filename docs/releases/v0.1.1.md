# SecondU v0.1.1

This update brings the full fictional example workspace to the website and makes existing English example conversations editable in the desktop app.

## One product, one set of examples

The website now renders the desktop application's actual interface with the same 万叶 and Caspian example spaces. Explore personal context, projects, specialist conversations, files and saved versions without credentials. Edits stay in the current browser page; the website does not connect to models, personal files or external accounts.

The landing page also introduces interactive expert badges from the product's own catalogue, a larger particle portrait, light and dark themes, custom language controls, and direct links into the workspace. Development directions open the existing product prototypes, with their current limits stated alongside the roadmap.

## Conversation editing

The original English example conversations now have stable links to their own saved message history. Editing a question creates a branch from that point and preserves the original conversation. The migration copies existing example text only, skips changed or removed conversations, and does not generate replies or imply model execution.

## Fixes

- Keep the website at its starting position while the embedded conversation scrolls to its latest message.
- Preserve embedded drafts and view state when expanding the workspace or changing site preferences.
- Release superseded browser export URLs instead of accumulating them after repeated exports.
- Keep team membership consistent when branching from an earlier message.
- Read the packaged application version from the root manifest so the app bundle and release agree.

## Download and run

The desktop download supports **Apple silicon Macs running macOS 13 or newer**. It is ad-hoc signed and has not been Apple-notarized. The archive is accompanied by `SHA256SUMS.txt`.

For source installation, model setup and troubleshooting, see [Quick start](../../QUICKSTART.md). Real execution requires your own model connection and authorized tools. The website is available at [yunyueli.github.io/SecondU](https://yunyueli.github.io/SecondU/).

This remains an early local prototype. Phone and glasses continuity, A2A services and Agent Dating are development directions, not connected production services. The existing [verification boundaries](v0.1.0.md#current-limits) continue to apply.
