# SecondU v0.1.0 — local personal-agent prototype

SecondU brings an inspectable personal digital twin, task conversations, specialist teams and versioned deliverables into one local desktop workspace. This is an early runnable prototype with explicit verification boundaries.

## Explore without credentials

Open the fictional Chinese or English example space to inspect a person's background, conversations, relationships, projects and files. The two example identities are separately authored and stored separately from personal records. Examples do not call models or connect real accounts.

The updated onboarding uses actual product components to show message revision branches, reactions and quotes, a lead's on-demand delegation, and format-specific artifact previews. The component catalogue and visual development record expose the design language and implementation decisions for review.

## Work with context, people and files

- Inspect and correct personal context while retaining sources, revision history and the distinction between confirmed facts, inferences and pending corrections.
- Start persistent tasks with a configured model. Revise a sent question into a new branch while preserving the original conversation; quote messages and add reactions.
- Build a small team from reusable specialist roles, appoint a lead and inspect actual dispatched workers, results and interruption state in the execution tree.
- Preview Markdown, highlighted code, CSV/TSV, static HTML/SVG, images and PDF. Optional local LibreOffice conversion enables read-only DOCX/XLSX/PPTX previews while preserving the original Office downloads.
- Browse saved artifact versions. The version label, preview and download follow the selected revision; unsaved drafts remain separate from saved downloads.

## Reliability improvements

Production CSS initializes the shared cascade before loading split stylesheets, preserving official SDK controls. The PDF reader uses a local PDF.js worker with correct MIME responses, page navigation and bounded rendering. Native startup checks the data-space identity and runtime fingerprint before reusing a backend; an older listener is left untouched.

The desktop dependency is pinned to Electron 44.5.1, whose installer uses Electron’s maintained ZIP extractor. The SDK’s Lodash dependency is overridden to patched 4.18.1. These replace the vulnerable earlier dependency chain; current audit and verification results are recorded separately from broad security guarantees.

## Install

The source requires Node.js 22.13 or newer; Node 22.18+ is recommended for the complete test workflow. Run `npm ci`, `npm run build` and `npm start`, then open `http://127.0.0.1:58645`. See [Quick start](../../QUICKSTART.md).

The desktop build targets **macOS 13 or newer on Apple silicon (arm64)**. Its app bundle is **ad-hoc signed and not Apple-notarized**. This is not a universal or Intel build, and no verified Windows native package is claimed. Source-build/local-test CI is configured for Node 22 on Linux and macOS; the linked Actions run is the evidence for its status, not this release text.

Real tasks additionally require an installed Codex CLI and the user's own model connection. The repository and application do not provide credentials or reuse the user's existing Codex login home. Provider requests may incur charges.

## What the evidence establishes

The product record includes one real DeepSeek team run using a synthetic arithmetic task: a lead delegated to one specialist, collected the result and summarized it; the execution tree and results persisted on reopen. This establishes that small execution path, not general reasoning or complex-team quality.

Local tests cover persistence, permissions, protocol fixtures, message revisions, original artifact bytes, saved versions and startup identity. Browser checks have exercised a synthetic PDF and modern Office preview paths. Those checks do not guarantee fidelity for every document. Updated build, package and release checks remain in the [development record](../DEVELOPMENT.md), [test guide](../TESTING.md) and [Actions](https://github.com/YunyueLi/SecondU/actions).

## Current limits

- Scheduled work depends on the local service being online. There is no cloud wakeup during computer sleep or shutdown.
- Real remote SSH hosts, external accounts and device synchronization require their own acceptance; local fixtures are not substitutes.
- Office preview requires LibreOffice and stays read-only. Static HTML/SVG preview does not run scripts or fetch outside resources; arbitrary TSX is not executed.
- Phone, glasses, marketplace, Dating and some communication/resource features are explicitly marked as development examples.
- This release does not establish production security, all-provider support, notarized distribution or measured improvements in user productivity.

The **Hither** name remains in internal IDs, environment variables and the macOS data directory to preserve existing local state. Do not delete existing data for the rename.
