# SecondU v0.1.5

发布于 2026-10-10。本版加入 macOS 应用内更新，可在 SecondU 中发现新版本、下载并安全重启。

## 变化

- **更新入口。** 在「设置 → 通用 → 应用更新」或 macOS 的 SecondU 菜单检查版本。发现更新后，侧栏底部显示下载入口；点击打开标准更新窗口，由用户确认下载、取消和安装。
- **后台发现。** 启动约 10 秒后、此后每 6 小时检查版本信息。尊重已跳过的版本，不自动弹窗、下载或重启。
- **真实进度。** 展示实际下载字节；总量未知时显示活动指示。下载、验签和安装由 Sparkle 处理。
- **保护当前工作。** 未发送草稿、未保存修改、保存或上传操作，以及活动任务会阻止退出与更新重启。超时不会强制停止任务。
- **关闭与重开。** macOS 红色关闭按钮隐藏并保留窗口和草稿，再次打开恢复原窗口。反馈保存期间禁用输入，避免保存中的编辑丢失。
- **更新校验。** 使用应用内置公钥验证更新包的 Ed25519 签名，区分连接错误、验签失败和无更新。

## 首次安装与适用范围

适用于 **Apple silicon（arm64）、macOS 13 或更新版本**。v0.1.4 及更早版本没有应用内更新入口，需要先手动安装支持更新的版本。

本版采用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证。更新包验签不替代首次安装包的来源验证，无需关闭系统安全检查。

本版已验证错误签名拒绝、草稿阻止重启、有效更新安装、数据与成果版本保留，以及手动检查更新。完整后台检查周期、所有网络异常和安装权限组合仍需分别验证。实现与测试范围见 [应用内更新](../APP-UPDATES.md)。
