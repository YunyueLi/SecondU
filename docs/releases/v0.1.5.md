# SecondU v0.1.5 — 候选

本版接入 macOS 应用内更新：在 SecondU 中发现新版本、查看真实下载进度，并在保存工作、确认任务安全后重启。当前为未发布候选；下列实现与源码验证不代表原生升级或公开发布已经完成。

## 变化

- **更新入口。** 可在设置的「应用更新」或 macOS 的 SecondU 菜单检查版本。发现更新后，侧栏底部显示蓝色下载入口；悬停或键盘聚焦可展开「更新」，折叠侧栏保留圆形入口。点击进入 Sparkle 标准更新窗口，由用户确认下载、取消和安装。
- **后台发现。** 启动约 10 秒后、此后每 6 小时，在更新空闲且没有进行中的会话时检查版本信息；已发现的更新保留入口，等待用户操作。该检查不自动弹窗或下载，尊重已跳过的版本；下载与重启仍由用户确认。
- **真实进度。** 原生适配累计 Sparkle 的公开下载字节回调，向侧栏和设置提供进度；总量未知时显示活动指示，不估算百分比。下载、验签和安装继续由官方 Sparkle 2.9.6 引擎处理。
- **保护当前工作。** 普通退出和更新重启共用草稿、未保存修改、保存／上传操作及活动任务检查。后端先暂停接纳新操作和调度，等待已接纳操作完成，复查各空间任务，再关闭资源。执行中、等待批准或远端执行尚未确认的任务会阻止退出；超时不强制停止任务或服务。
- **关闭与重开。** macOS 红色关闭按钮隐藏并保留原窗口和草稿；再次打开应用恢复同一窗口。真正退出仍须通过安全检查。服务部分关闭或退出确认失败后保持冻结；启动重试不会覆盖仍在运行的自有服务句柄。
- **更新真实性。** 更新包使用应用内置公钥验证 Ed25519 签名。版本不兼容、网络错误和验签失败分别呈现，不统一显示为「已是最新版本」。

侧栏参考了本机 Codex 安装包的静态交互实现。SecondU 采用手动下载，因此「发现但尚未下载」也显示入口；此处是产品适配，不与 Codex 的内部阶段逐项同义。

## 首次安装与适用范围

v0.1.4 及更早版本没有内置更新入口，须手动安装一次首个具备更新功能的版本。后续更新通过应用入口和正式更新渠道继续。

本候选针对 **Apple silicon（arm64）、macOS 13 或更新版本**。应用仍采用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证；后续更新包验签不替代首次安装包的来源验证，也不表示已获 Apple 公证。无需关闭系统安全检查。

## 已取得的验证

- 源码专项覆盖更新状态白名单、真实字节范围、原生重启 token 的取消与一次性消费、草稿状态聚合，以及退出拒绝后再次尝试。主进程事件回归确认窗口隐藏／恢复、普通退出不依赖更新就绪、不可恢复关闭失败保持冻结，以及启动重试保留现存服务句柄。
- 后端专项覆盖慢请求体、主空间与子空间、等待批准、委派和未确认远端执行、调度暂停／恢复、OAuth 回调收尾、取消与超时，并用真实子进程验证准备成功后仍存活、提交关闭后才退出。
- appcast 工具以模拟签名测试固定发布地址、文件长度与摘要、说明转义、归档变化拒绝和禁止覆写；该测试不读取 Keychain，也不替代最终 ZIP 的正式签名与原生验签。
- 本轮 Kimi K3 max 使用产品合成状态截图及对应差异进行视觉辅助复核，在可见范围内未发现阻断问题。已采纳减少展开侧栏重复提示、让字号跟随产品设置的建议。合成状态不证明真实下载或安装；Codex 参考源码和个人资料未提交给该复核。
