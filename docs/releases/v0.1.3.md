# SecondU v0.1.3

Published / 已发布：2026-10-02。

Desktop runtime source: [`30d7a7a`](https://github.com/YunyueLi/SecondU/commit/30d7a7a5ad7d3f2275fa9966b18cd8f4eb831f1c).

- Align native macOS title-bar controls and keep the navigation toggle's click target separate from draggable window surfaces, including after collapse.
- Add a 24-scenario context benchmark across three conditions and two repetitions: **144 recorded attempts, 143 replies and one timeout**. Raw retrieval passed 48/48 decision checks; structured context passed 43/48. The concise website summary links to a separate report with exact inputs, replies, scores and retained failures. This run does not establish a structured-context advantage.
- Keep upright, ordered 2ndU characters clear of the portrait's actual alpha boundary and the title/body text's glyph shapes, while retaining interaction in the surrounding whitespace.
- Reuse the product startup screen in the embedded workspace, repair deployment-subpath resources and confirm readiness after iframe load. Loading errors offer an explicit retry.
- Add a dedicated privacy illustration and update the bilingual benchmark and artwork documentation.

Checks covered application startup, archive integrity, read-only MCP, ad-hoc signatures and native sidebar behavior, including fullscreen. These checks do not establish model quality or performance on every device.

The desktop app supports **Apple silicon Macs running macOS 13 or newer** and is not Apple-notarized. Verify the archive against its accompanying `SHA256SUMS.txt`. See [Quick start](https://github.com/YunyueLi/SecondU/blob/main/QUICKSTART.md) and [benchmark methodology and results](https://github.com/YunyueLi/SecondU/blob/main/docs/CONTEXT-BENCHMARK.md).
