# SecondU v0.1.4

本版完善工作过程的真实状态和双语官网体验。[v0.1.4](https://github.com/YunyueLi/SecondU/releases/tag/v0.1.4) 已于 **2026-10-08 05:16:38 UTC（北京时间 13:16:38）**公开发布；候选验收、公开资产与上线结果分别记录。

## 变化

- 过程摘要与个人背景入口对齐，默认收起。展开查看工具、计划和协作，按真实调用归并开始与结果；详情继续使用原工作台和原始记录。
- 区分等待批准、需要补充、审查、失败、停止和中断。远端观察未确认时明确提示，停止推算实时耗时，不把断联当作任务已停止。
- 直接复用 Apps SDK UI 的图标和加载组件；参考 Codex 事件协议与 DeepSeek Harness 的聚合和分层，保留必要的业务状态适配。
- 官网改善手机首屏、路线详情、文字入口和产品体验的焦点返回；暂停 Hero 时清除字符残影，保留人物静帧。补齐主题启动、中英文静态分享标签和公开分享图。
- 六幅路线与隐私图的交付总量从 9,108,380 字节降至 580,364 字节，原图不变。这个比例只表示文件体积变化。
