# SecondU v0.1.4

发布于 2026-10-08。本版完善工作过程的状态展示和双语官网体验。

## 变化

- 工作过程摘要与个人背景入口对齐，默认收起；展开后查看工具、计划和协作记录。
- 区分等待批准、需要补充、失败、停止和中断。远端状态未确认时明确提示，并停止推算实时耗时。
- 改善官网手机首屏、路线详情、文字入口和产品体验的焦点返回；暂停首页动画时清除字符残影，保留人物静帧。
- 补齐主题启动、中英文分享标签和分享图；六幅路线与隐私插画的交付总量从约 9.1 MB 降至 0.58 MB，原图保持不变。

## 安装与使用

适用于 **Apple silicon（arm64）、macOS 13 或更新版本**。安装包采用 ad-hoc 签名，未经 Apple 公证。请从本版本的 GitHub Release 下载，并使用随附校验文件核对安装包。

网页示例使用虚构资料，编辑仅保留在当前页面。真实模型调用和外部账号需要用户单独配置；浏览器手机宽度检查不代表真实手机或公网性能验证。

本版已完成源码检查、应用启动、历史对话与成果保留、安装包签名与完整性检查；官网检查覆盖中英文、浅深主题、桌面及手机宽度，并验证键盘进入、退出和焦点返回。性能测量条件见 [官网品质说明](../WEBSITE-QUALITY.md)。
