# 财务工作区

从侧栏“更多”打开财务，可按空间固定到侧栏。首次引导可连接账户、手动录入和选择展示币种，之后也可继续调整。

| 页面 | 可以做什么 |
| --- | --- |
| 财务总览 | 查看资产结构、占比和明细，配置 13 类总览组件，切换展示币种和金额显隐。 |
| 我的账户 | 保存现金、投资和其他资产，查看来源、原币金额及日期，归档与恢复账户。 |
| 投资持仓 | 录入和编辑手动持仓，核对来源持仓及可用行情。 |
| 市场行情 | 管理自选、刷新支持品种的报价，查看来源时间及行情状态。 |
| 负债与还款 | 记录和筛选负债，管理本金、还款与关联资产。 |
| 收支记录 | 管理收入、支出、退款、转账，导入 CSV，整理账单、订阅与周期收入。 |
| 财务规划 | 设置目标、预算、情景方案、信用记录和财务记忆，生成周报。 |

## 在线体验

[官网财务展示](https://yunyueli.github.io/SecondU/?lang=zh#finance)提供概览、投资、结构、占比、明细和持仓六个视图。双语虚构示例涵盖银行与券商账户、401(k)、Roth IRA、HSA、公司股票、ESPP 和外币现金，以及相应的收支和长期计划。

概览包含净资产变化、分类支出、本月支出和即将到期；投资包含投资组合、持仓行情与信用评分。点击预览可进入[完整工作区](https://yunyueli.github.io/SecondU/product/embed.html?space=demo-cn-v1&lang=zh#finance)，浏览页面、筛选和查看记录。在桌面版中添加自己的记录、配置账户连接并更新行情。本机运行网站的方法见[官网说明](../website/README.md)。

## 连接账户

在“设置 → 连接器”选择服务，按详情中的准备条件完成配置与授权。预览返回的账户，选择并对应已有记录后同步。凭据保存在当前空间的本机加密存储中。

| 来源 | 可读取内容 | 配置要点 |
| --- | --- | --- |
| Moomoo | 账户、资金与持仓 | 选择 AppKey 或 OAuth 接入方式，开通对应读取权限。 |
| Plaid | 账户、余额、交易、投资持仓与负债 | 配置自己的应用，通过 Hosted Link 授权；字段由机构及开通产品决定。 |
| Teller | 美国银行账户、余额、交易及适用的负债信息 | 使用 Connect，配置应用的 mTLS 证书及对应环境。 |
| TrueLayer | 英国银行账户、余额与交易 | 使用 Data API v3，配置应用权限和回调地址。 |
| Interactive Brokers Flex | 报表中的账户净值与期末持仓 | 配置 Flex Token、Query ID 和报表字段，记录保留报表日期。 |
| SnapTrade Personal | 已连接账户的净值与持仓 | 配置 Personal Client ID 与 Consumer Key，记录保留来源更新时间。 |

重新授权后可接续原账户；旧账户可保留历史或归档。同步按来源标识匹配账户和流水，失败时保留已有记录，并显示同步状态。

## 记录与估值

CSV 导入先核对列映射、日期格式和默认币种，再预览确认。修正错误行后保存，重复检查使用文件校验值与原始行号。转账单独统计，账户余额可在账户记录中核对和更新。

周期计划支持单次、周、月、季度、年度和间隔。付款或收款可关联具体发生期，并保留部分付款及下一期。月／年合计按周期折算。

房产、车辆、贵重物品、保险现金价值、应收款与企业权益可手动填写估值、本人份额、来源和日期，并关联贷款。来源账户可调整本地名称、说明和分类。

资产统计区分原币与展示币种、账户净值与持仓，以及账面日期与报价时间。自动行情支持已匹配的美港股票及 ETF、境内基金净值与汇率；时间提示显示行情采用的时区，日期型净值保留原始日期。

## 规划、周报与对话

信用记录可填写机构、模型、量表、日期和因素，并比较同一口径的历史。情景规划使用可调整的假设，帮助比较不同安排。

周报比较最近七天与此前七天的收支，汇总未来七天计划、净资产与信用记录，保存为 Markdown 和附带来源的 JSON。可手动生成，也可在自动化中启用每七天一次的整理；定时运行期间保持本机服务在线。

通过“聊聊财务”等入口，把选中的记录整理为对话草稿和快照附件；发送前可检查或调整内容。

## 金融研究

连接器目录提供 Alpha Vantage、Morningstar、FactSet、Daloopa、Fiscal.ai、Quartr Pro、Crunchbase、Financial Modeling Prep 和 LSEG 的研究接口。打开服务详情查看订阅、OAuth 注册、令牌或 API key 配置步骤。FMP 使用独立密钥栏，Daloopa 使用 MCP token。
