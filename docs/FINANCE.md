# 财务工作区

从侧栏“更多”打开财务，可按空间固定到侧栏。首次引导支持连接账户、手动录入和选择展示币种；跳过后可继续设置。七个页面共用 SecondU 的资料、对话、连接器与设置，不另建独立财务应用。

| 页面 | 可以做什么 |
| --- | --- |
| 财务总览 | 查看资产全景的结构、占比、明细与全部视图；按数据可用性显示并编辑 13 类总览组件，切换展示币种和金额显隐。 |
| 我的账户 | 保存现金、投资和手动估值资产，查看来源账户、原币金额及记录日期，归档与恢复账户。 |
| 投资持仓 | 录入、编辑和核对手动账户持仓，查看来源持仓与可用行情；账户总额与持仓不重复累加。 |
| 市场行情 | 管理自选、刷新支持品种的报价，查看来源时间、延迟、收市、上次值或未匹配状态。 |
| 负债与还款 | 记录并筛选负债，保留本金与还款相关记录；关联资产的贷款仍只计入一次负债。 |
| 收支记录 | 管理收入、支出、退款、转账；核对导入 CSV；管理账单、订阅与周期收入。 |
| 财务规划 | 保存目标、预算、情景试算、信用记录和财务记忆，生成本机财务周报。 |

## 虚构示例

官网采用独立虚构财务人物 Alex Morgan，一位居住在 San Mateo、任职于虚构公司 Aster Vale AI 的资深 AI 基础设施工程师。中英文共用截至 2026 年 10 月 25 日的同一份只读快照：11 个资产账户、3 项负债、19 条持仓、119 条交易及 22 项周期计划。总资产 729,096.75 美元，已记录负债 16,480.75 美元，净资产 712,616.00 美元，原币与折算口径分别保留。

示例覆盖银行与券商账户、401(k)、Roth IRA、HSA、已归属公司股票、ESPP 和外币现金。未归属股票及未行权期权不计入资产；工资入账、账户转账与股票售款区分记录。机构和证券名称真实，人物、账户、持仓、交易、价格与汇率均为预先编写的虚构数据，不连接真实账户，也不改写中英文数字分身示例的人物资料。示例报价按 `America/Los_Angeles` 时区显示。

[官网财务展示](https://yunyueli.github.io/SecondU/?lang=zh#finance)提供概览、投资、结构、占比、明细和持仓六个视图：概览使用净资产变化、分类支出、本月支出、即将到期四个原生组件，投资使用投资组合、持仓行情与信用评分。点击后可进入[完整财务工作区](https://yunyueli.github.io/SecondU/product/embed.html?space=demo-cn-v1&lang=zh#finance)，浏览七个页面、调整筛选并查看记录。网站示例不保存新增财务记录、不连接账户或更新真实行情；添加记录与真实连接需要桌面版。本机运行网站的方法见[官网说明](../website/README.md)。

## 账户连接

在“设置 → 连接器”选择服务，先查看地区、所需权限和准备条件，再进行配置与授权。预览只读取；选择账户并明确对应已有记录后才同步。凭据保存在当前空间的本机加密存储中，界面状态查询不会触发外部读取。

| 来源 | 当前适配范围 | 需要注意 |
| --- | --- | --- |
| Moomoo | AppKey 或 OAuth 方式下的已支持账户、资金与持仓只读读取 | 接入方式、账户和读取权限由服务商授权决定；连接成功与成功读取分开显示。 |
| Plaid | 账户、余额、交易、投资持仓、负债 | 地区、机构及已开通产品决定实际字段；使用自己的应用配置与 Hosted Link 授权。 |
| Teller | 美国银行账户、余额、交易与适用的负债信息 | 使用官方 Connect；真实数据需要应用的 mTLS 证书和相应环境权限。 |
| TrueLayer | Data API v3 的英国银行账户、余额与交易 | 需要应用权限、注册回调与本人授权。 |
| Interactive Brokers Flex | 报表中的账户净值与期末持仓 | 需要自己的 Flex Token、Query ID 和完整报表字段；使用报表日期，不导入交易流水。 |
| SnapTrade Personal | 已连接实盘账户的净值与持仓 | 需要自己的 Personal Client ID 与 Consumer Key；使用来源缓存并保留更新时间，不导入交易流水。 |

重新授权后可显式接续原账户；未再返回的旧账户需要决定保留历史或归档。同一来源不能重复对应多个本地账户。流水通过稳定来源标识去重，来源记录只读；撤回仅作用于供应方明确声明的完整日期范围。同步失败保留已有数据并标注旧状态，沙盒只预览，不写入正式资产。

这些是当前适配器的实现边界，不能据此认定某个用户已获服务许可或所有机构均已完成真实账号验收。本轮新供应商的授权、对应、接续与去重主要使用隔离数据验证。连接器不提供证券下单、付款或转账。

## 记录、估值与统计

CSV 导入先核对列映射、日期格式和默认币种，再预览确认；错误行阻止整批保存。重复检查使用文件校验值与原始行号，不合并同一天、同金额的不同交易。转账独立记录，不进入收入／支出合计；收支记录不会自动改写账户余额。

周期计划支持单次、周、月、季度、年度和间隔。实际付款或收款关联具体发生期，保留部分付款及下一期；计划不等于扣款已经发生。月／年合计按周期折算，单次计划不纳入周期合计。

房地产、车辆、贵重物品、保险现金价值、应收款与企业权益支持总估值、本人份额、来源和日期，以及已有贷款关联。保险只记录现金价值；系统不会自动估价房产、车辆或保单。来源账户的本地名称、说明和分类不回写供应方金额。

原币与展示币种、账户净值与持仓、账面日期与报价时间分别保留。缺失汇率、缺少历史或无法匹配的报价维持缺失。自动行情限于当前已支持且身份与币种可确认的美港股票及 ETF、境内基金已公布净值与汇率；债券、黄金、加密资产、期权和期货类别不自动获得全面报价支持。

## 规划、周报与对话

信用记录由本人填写机构、模型、量表、日期和因素，只比较同一口径的历史；没有自动征信或未提供阈值的评级。情景试算采用显式假设，不写成已发生事实。

周报比较最近七天与此前七天的已记录收支，列出未来七天计划，保留净资产和信用记录的实际日期。它只读本机保存的记录与汇率，不调用模型或账户服务，也不修改财务记录。可以手动运行，或在自动化里启用每七天一次的整理；自动化默认暂停，需要本机服务持续运行。成果保存为 Markdown 和包含来源标识的 JSON。

“聊聊财务”等入口只准备草稿和限定范围的快照附件，发送前可以检查或移除。快照不包含凭据、账户尾号或私人运行日志；发送后使用哪个模型仍遵循已有对话流程。记录范围有限时，结果不会被称为完整银行流水。

## 金融研究连接

连接目录另提供 Alpha Vantage、Morningstar、FactSet、Daloopa、Fiscal.ai、Quartr Pro、Crunchbase、Financial Modeling Prep 和 LSEG 的官方研究接口。研究权限与账户同步互相独立；目录展示不表示已连接或具备数据许可。Quartr Pro 受个人订阅资格限制，LSEG 标为预览；各服务的 OAuth 注册、令牌或 API key 要求以详情说明为准。FMP 密钥放在独立密钥栏，不写入地址；Daloopa 使用其 MCP token。

Experian、PitchBook 等未有本应用已确认可用的接入契约，未作为可自动连接的能力交付。实现、测试与实际运行范围见[开发历程](DEVELOPMENT.md#2026-10-24-真实财务服务目录与-agents-导航)。
