# 输入与侧栏检查

本文记录 2026-09-29 至 2026-09-30 的历史检查，使用公开图片、合成文本与虚构演示空间，未调用云模型。结果只适用于当时的界面与所列场景。

## 附件、链接与侧栏

- 剪贴板 PNG 粘贴后显示附件草稿，文字为空也能发送。
- 通过文件选择器添加文本后，从消息下载的文件与原件逐字节一致。
- HTML 剪贴板中的锚点转为 Markdown，保留完整 query/hash；外链使用 `target="_blank" rel="noopener noreferrer"`。目标网页的实际加载未在这批检查中确认。
- 刷新并重开同一对话后，图片仍可打开原图预览，文本附件下载入口保留。
- 对话归档、恢复和再次归档后，原消息与附件引用保持。
- 群聊空输入在 1280px 和 390px 宽度下均为 32px 高，无页面横向溢出。引用按钮为 28×28px、图标为 18×18px，390px 下引用内容不溢出。
- 最近对话保持单行，完整名称与有意义的状态可通过 title/aria 读取。列表可滚动到底，末行高亮完整显示。
- 搜索控件独立于列表滚动区；平台筛选菜单的 17 个选项已检查图标与文字居中，SVG 保持各自图形比例。

## 群聊工作区与运行设置

在虚构演示空间完成本地任务批准、生成文件、右栏预览、编辑保存新版本及 390px 弹层关闭。关闭后群聊草稿、引用消息和成员保留；聊天与工作区独立滚动，输入区固定。后续普通答复不会显示任务完成条，已有文件仍留在所属消息后，并可打开已保存版本。

缺少模型配置时，按角色运行明确停在配置错误，不发送模型请求。此时仍可调整数字分身与运行模式；继续任务使用当前保存的配置。运行和等待批准期间的模式保持锁定。

已解决的模型配置错误不会让后续普通答复被当作已完成工作。底部进展依据实际动作、计划、文件或当前待处理问题展示，旧错误仍可从会话菜单查看。相关定向测试与类型检查通过，未进行真实云模型调用。

## 已有对话输入区两行布局

已有普通任务以及助理私聊、群聊采用上方文本区、下方附件与模型、语音、发送控件的两行布局。新对话首页使用紧凑单行，长文本或附件按内容展开。布局状态调整不改变发送、审批、模型选择或附件处理逻辑。

在 1123px 与 390px 宽度下，已检查空输入与短草稿保持两行、文本区与操作栏不重叠；模型菜单开关保留草稿，Shift+Enter 换行不发送；群聊引用与草稿同时保留。新对话首页在两种宽度下仍为一行，未出现页面横向溢出。
