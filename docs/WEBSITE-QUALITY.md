# 官网品质标准与验收

维护日期：2026-10-08。用户要求 SecondU 官网以 Awwwards、The Webby Awards、FWA 可获奖作品的品质为目标，持续自检、修正并重新验收。本页把目标落实为可检查的设计与交付要求；实际获奖由各奖项评审决定，不使用内部打分宣称已经达到获奖水平。

本页维护官网的长期标准与本轮证据范围。产品能力边界见 [产品定位](PRODUCT.md#官网中的能力与体验入口)，实际修改、取舍与发布结果继续记在 [开发历程](DEVELOPMENT.md) 和 [迭代清单](ITERATION.md)，不另造发布历史。

## 官方标准及采用方式

以下来源于 2026-10-08 核对的官方页面。评审机制可能变化，正式参评前重新核对。

| 来源 | 官方维度 | SecondU 对应的检查重点 |
| --- | --- | --- |
| [Awwwards Evaluation System](https://www.awwwards.com/about-evaluation/) | 设计 40%、可用性 30%、创意 20%、内容 10% | 构图、字体和材质形成完整表达；用户能顺畅阅读、操作和进入产品；原创交互服务于数字分身主题；内容具体、可信 |
| [The Webby Awards Judging Criteria](https://www.webbyawards.com/judging-criteria/) | 当前网站类别包含内容、结构与导航、视觉设计、功能、交互、创新、整体体验 | 从理解产品到实际参与形成连续体验；检查加载、跨浏览器、访问需求、导航预期和交互反馈，不能只检查首页画面 |
| [FWA 官方介绍](https://thefwa.com/FWA25/25.html) | 强调数字创新、创造性、原创性和技术质量 | 保留有辨识度的艺术方向，让细节、交互和实现共同服务于产品表达。此页面是官方方向说明；本轮没有核实到可引用的数字权重 |

官方维度用于确定审查范围，不换算为自评获奖分数。功能检查通过、性能分数、外部模型意见和某张满意截图，都不能单独替代完整品质判断。

## 保留的艺术与产品方向

- Hero 保留已经确认的完整双面人物、奶油色与淡紫色油画材质、粒子边缘及层次。纸面、水彩与手绘质感贯穿插画、背景和细节；不要把不同材质统一成单层模糊或通用科技光效。
- `2ndU` 保持固定字符顺序和正立方向。粒子反馈、首次聚合及局部悬停遵循既定行为，文字与按钮周围保留安全距离，不能因增加效果而降低可读性。
- 保留现有字体、配色与中英文分别调整的比例。标题、正文和真实产品界面的字体角色清晰，避免把整站排成同一种展示字号。
- 展示真实 SecondU 组件、专家工牌、对话和可编辑成果。官网示例继续明确标注虚构内容、页面内状态与执行边界，不用装饰性模拟界面证明尚未存在的能力。
- 手机端按阅读与操作重新组织内容。桌面构图可以调整为适合窄屏的顺序，完整产品方向、状态说明和操作能力仍应可达。

## 每轮检查与修正

每轮先固定候选版本、入口、浏览器、尺寸、语言和主题，实际滚动并操作受影响页面，记录具体问题及其后果。修正后在相同条件下重开页面；涉及公共组件时补查受影响的其他组合。只有看到新行为和新画面，才把对应问题改为已验证。

每条记录至少包含：问题、发生条件、实际修改、验证结果、证据位置和剩余限制。通过后不重复扩大同一批检查；发现新变化、失败或未解决问题时，再进入下一轮。保留历史失败及其范围，不能用新版截图改写旧版结果。

## 性能证据的解释范围

性能记录须注明 URL、候选版本、浏览器、视口、像素比例、网络设置、缓存状态、采样时长及测量方法。开发服务器与生产构建、冷缓存与热缓存、实验室网络与公网分别记录；前后对比使用一致条件。

图片字节减少说明交付资源更小，不直接等于首屏更快。实际传输还取决于加载时机、缓存、压缩与访问路径。页面 requestAnimationFrame 反映主线程调度，WebGL 提交帧反映发出的绘制调用；两者都不能证明 GPU 完成时间或所有设备恒定帧率。本机运行也不能替代真实用户的 LCP、INP、CLS 数据。没有取得的指标写为未测，不用近似指标充当结果。

最终性能复核至少覆盖首屏冷开、完整滚动、关键交互、暂停、离屏与后台恢复，并检查新增资源及长任务。数值异常需定位到具体工作或请求；不能为得到更高分数删去已确认的产品表达。
