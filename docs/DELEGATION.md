# 受限分身与本机能力分享

受限分身把本人确认的一项专业能力、脱敏背景和服务规则保存为发布快照。接收者持有独立授权，通过本机接收页或 A2A 文本接口提出请求。本人可以逐次审批、拒绝请求、撤销单个接收者或撤销整项能力。

当前只在运行 SecondU 的这台设备上可用。应用不自动开启外网、局域网监听、隧道或云托管；扫码也不会把本机地址变成跨设备服务。匹配与交易用途只产生文本建议或意向，不包含联系人匹配平台、消息发送、付款、合同或履约。

## 使用流程

1. 在自己的空间连接一个 API key 模型，打开助理详情中的能力分享入口。
2. 填写能力说明、允许使用的脱敏背景、用途、服务规则、有效期和调用次数。原助理说明、个人认知、来源、文件和联系人不会自动复制到发布内容。
3. 核对并勾选当前内容授权，发布到本机。自动调用需要单独明确授权；默认逐次审批。
4. 为接收者设置备注、用途、期限、次数和是否可以调用，生成链接或二维码。持有完整链接者拥有对应权限，因此每份链接应单独管理。
5. 接收者提交请求。本人在“请求”页批准或拒绝；批准后才发送模型请求。
6. 本人与接收者查看结果。撤销立即禁止后续访问，并中断未完成调用；重新发布会撤销旧版本的所有授权。

## 数据与执行边界

- 管理界面使用原有的本机 API 来源校验。接收页和 A2A 服务独立监听 `127.0.0.1` 的另一端口，不与个人空间同源，也不提供个人 API 或文件服务。
- 发布快照只包含表单中的能力说明、脱敏背景和服务规则。单轮执行器只将该快照和当前请求发给明确绑定的 API key 模型，不调用 `TaskRunner`，没有工具、个人认知、工作目录或连接器入口。
- 支持 Responses、Chat Completions 与 Anthropic Messages 的完整非空文本结果。工具请求不会执行；错误、未完成响应、配置变化或服务中断都不会标记成功。没有模型配置时不会使用示例答复替代。
- 每次发布固定模型连接的版本、地址、协议和模型。连接改变后必须重新发布。运行中配置变化会丢弃结果。
- 授权令牌为 32 字节随机值，只保存 SHA-256 摘要。完整令牌仅在创建时返回，链接使用 URL 片段；接收页读取后清除片段，不写浏览器持久存储。管理列表、公开能力名片和审计事件不返回令牌。
- 接收者只能查询和取消自己授权下的任务。相同 `messageId` 与相同输入返回同一任务；复用该标识提交不同输入会失败，不会重复扣减次数。
- 结果返回前再次核验授权，避免完成与撤销之间的竞争。重启时，遗留的 `SUBMITTED`、`WORKING` 任务明确失败，不自动重试；等待本人授权的请求继续等待。
- 记录保存在本机独立集合中，不进入常规 bootstrap、个人认知或普通任务列表。撤销保留本人的调用记录，也无法收回接收者已经取得的结果副本。

## 接口范围

依据 [A2A 1.0 规范](https://a2a-protocol.org/latest/specification/) 实现文本交互子集，未声明完整协议或跨产品互通验收。

| 接口 | 行为 |
| --- | --- |
| `GET /share/:id/.well-known/agent-card.json` | Bearer 授权后的能力名片；仅展示允许的用途与服务规则 |
| `POST /a2a/:id` | JSON-RPC 2.0，要求 `A2A-Version: 1.0` |
| `SendMessage` | 一个新的 `ROLE_USER` 文本消息；用途由 `metadata.purpose` 指定；不接续其他任务 |
| `GetTask` | 当前授权下的任务及结果，支持 `historyLength` |
| `ListTasks` | 按接收者隔离，按更新时间倒序；支持游标分页、状态／上下文／更新时间过滤和产物开关 |
| `CancelTask` | 取消当前授权下尚未结束的请求 |

`SendMessage.configuration.returnImmediately=true` 立即返回任务；默认等待终态或中断态。需要本人审批时使用 `TASK_STATE_AUTH_REQUIRED`。能力名片明确关闭流式、推送与扩展名片，不接受文件、工具调用、回调地址或隐式个人上下文。

管理 API 位于当前空间的 `/api/delegations`：创建／更新草稿，`/:id/publish` 发布，`/:id/grants` 发放授权，`/:id/grants/:grantId/revoke` 撤销授权，`/:id/calls/:callId/approve|reject` 处理请求，`/:id/revoke` 撤销能力。示例空间禁止这些写入。
