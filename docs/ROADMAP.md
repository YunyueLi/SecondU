# SecondU 完整产品路线

SecondU 是以个人数字分身为核心的智能体产品。它持续理解一个人的背景、经历、偏好、目标、关系与现实处境，在不同任务、应用和设备之间延续这些理解，主动帮助用户处理工作与生活中的事务，并支持协作、社交和专业服务。专业智能体、工具与执行环境根据具体需要，在用户授权范围内参与。

这条路线承接已经确定的 [完整产品定位](PRODUCT.md)。个人上下文、实际事务执行、多设备连续体验和可控的能力分发共同构成产品，不把定位缩减为聊天角色、画像展示或一次性任务助手。

## 三项重点价值

- **少重复解释。** 已经说明过的经历、偏好、目标和取舍可以持续维护，在新的事情中按相关性使用；重要理解有来源，可以纠正。
- **全量多模态上下文连续流转。** 原始文字、照片、画面、语音、来源、当前任务和成果版本在不同设备与场景之间接续。全量管理不等于向每一次模型调用或每个接收者开放全部资料。
- **个人专业能力可以分发。** 用户选择知识、经验和材料，形成用途明确、可撤回的专业分身，支持人与 Agent、Agent 与 Agent 之间的协作、社交与服务交易。

## 从完整方向到实际交付

以下按依赖关系推进，不承诺未经验证的上线日期。已有代码、本地协议测试、真实模型任务、跨设备硬件和商业服务分别验收。网站和产品中标注 Dev 的内容可以用于体验方向，不能被描述为已接通真实服务。

## 阶段安排

### 桌面基础与可重复运行

先完成并持续维护个人认知、任务、团队、成果、权限和恢复链路。公开仓库具备干净安装、测试、构建、真实页面验收以及清晰的运行要求。当前主交付面为本机桌面；多格式成果要保留原件，不靠文件扩展名假装预览成功。

### 长期协作与真实场景

让用户在真实工作和生活事项中持续使用，记录重复解释是否减少、理解是否准确、结果是否合适、恢复是否可靠。完善主动职责、实际连接器和远程环境。以可观察的状态与真实回执衡量进展，不以模型轮数、角色数或演示动画代替效果。

### 连续的设备与场景

在桌面基础上连接真实手机和眼镜。文字、图像、语音、现场来源、个人认知、任务状态和产物版本都纳入接续；验证权限、带宽、离线恢复和版本冲突。不同设备分别承担现场记录、复杂处理和随时确认。

### 专业能力网络与现实连接

从明确用途的受限分身开始，验证远程分享和真实 A2A 互通，再推进服务目录、委托履约、支付结算和双向社交。社交和交易沿各自条件验收，不因同属 Agent 网络就合并授权。

### 长期个人资产

持续保留原始资料与可迁移记录，让新资料和模型进步能改进个人认知。将真正有用的任务反馈、被采用的判断和经过验证的方法用于下一次工作，并观察长期效果。
