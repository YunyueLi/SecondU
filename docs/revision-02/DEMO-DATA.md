## 升级保护

- `server/fixtures/demo-baseline-v3.json` 是改写前的作者默认记录快照，包含仓库 HEAD 与本轮早期版本的差异、生命周期补充和原文件哈希；不包含用户数据。
- 升级只进入 `profile.demo === true` 且尚未使用当前匹配器版本的空间。每条现存记录须与已归档旧默认完整哈希匹配，才能替换。只有生成时的时间戳采用占位符比对，其余字段、额外字段和版本历史均参与检查。
- 已修改记录、已删除旧默认、导入来源、有人使用的会话保留。正式或用户修改记录引用的旧人物、助理与来源一并保护；被保留记录的原证据不会在它下面被重写。
- 旧事实升级增加版本并保留历史。原任务 prompt、消息、成果、自动化、模型配置和真实导入内容不参与迁移。旧默认来源保存在基线快照中。
- 所有写入和升级标记在同一 SQLite 事务中完成。标记包含更新/新增/保留的 ID 及更新前后哈希。相同匹配器版本重启不重复迁移；正式个人空间完全跳过。匹配器版本 2 额外识别已核实的早期 FactRevision 缺少 kind/sourceIds 版本，其余原字段仍须完整一致。
- 若某些示例已被修改或被正式记录引用，相应旧内容会保留，空间可能同时出现两代示例。这是保护用户内容的结果，不能为追求视觉一致而覆盖。

## 独立产品工程师示例空间

设置 → 个人空间 →「进入示例空间」先创建固定独立目录 `spaces/demo-engineer-v4`，再通过 `?space=demo-engineer-v4` 打开。同源接口 `/api/spaces/demo-engineer-v4/...` 使用独立 Store、SQLite、任务工作目录与凭据；不复制原空间密钥。只有这个固定空间名有效，不接受任意路径，目录软链接会被拒绝。空间不存在时数据接口返回 404，不回退到原空间。

可随时「返回原空间」。再次进入或重启后保留该示例空间内的修改，绝不自动重置。切换整页重载，页面说明先保存未提交表单；两个空间的已保存内容分别保留，切换本身不取消任务。示例执行器在首次访问此空间时启动，重启后的任务按正常中断恢复规则处理，不自动重放。

API 请求、头像、背景图、成果下载和导出使用当前空间命名空间。会话草稿、成果草稿、收藏及外观缓存分别加空间前缀；语言和侧栏宽度作为应用偏好共享。项目与模型连接也跟随所属数据库隔离。
