# 认知区：关系图谱与外部会话

本轮直接实现可操作的图谱与通信记录浏览器。基础控件、图标和明暗主题使用官方 Apps SDK UI；关系画布、会话布局与来源引用属于业务组合。

## 人物关系

入口为 `#relationships`，实现位于 `src/cognition/RelationshipGraph.tsx`。

- 使用 d3-force，根据真实人物和关系计算位置，不再预排为中心人物加圆周节点。
- 拖动节点调整布局，拖动画布平移；滚轮和按钮缩放。方向键平移，加减键缩放，Home 适应可见图谱。
- 检索人物姓名与背景并定位；按关系类型筛选；双击人物或点击“聚焦关系”查看一阶邻域；悬停和选中时突出相关节点与连边。
- 右侧展示人物背景、关联人物、具体关系与原始依据，可跳转关联人物、编辑人物、修正关系。节点拖拽只改变当前布局，不改写事实。
- 不超过 120 个节点时用 SVG 保留可聚焦节点。更大的图使用 Canvas，按设备像素比绘制，通过 RAF 合并重绘、合批绘制连边、裁剪视口外节点，避免在模拟每一帧创建大量 DOM。两个渲染分支复用同一布局与交互状态。
- 小比例隐藏一般标签；聚焦和选中标签保持可读。Canvas 同样提供人物检索和人物索引，详情与来源入口不依赖画布文字。

主要样式在 `src/cognition/explorer.css`。显示时仅将早期自有示例角色“我（虚构示例）”规范化，导入原话和 `sources.text` 不做替换。

## 外部会话

入口为 `#conversations`，实现位于 `ConversationInbox.tsx` 和 `ConversationFileImport.tsx`。

左侧为会话与来源平台，中间为按日期排列的原始消息，右侧为参与者、已知关系和记录来源。支持联系人与消息搜索、平台筛选、人物资料编辑与来源查看。当前流程不提供向联系人发送消息的输入框。

长会话首先展示最近 100 条，按需加载更早记录并保留滚动位置；搜索时显示匹配消息。较窄窗口可切换会话列表，资料栏以可关闭浮层呈现。

导入流程是文件选择或拖入、服务端预览、用户确认、提交结果。界面展示参与者、原始消息、全量数、重复数和警告；预览截断时明确提示实际导入数量。文件上限为 1 MiB。

- 通用协议为 `hither.chat.v1`，顶层字段为 `format`。界面可下载 JSON 示例。
- Instagram 支持原始 `message_*.json`；微信和 WhatsApp 当前需要规范 JSON 文件，不代表账号已连接或已读取加密数据库。
- 接口为 `POST /api/imports/chat/preview` 与 `POST /api/imports/chat/commit`。账号标识用于后续合并；原始文件保留为来源，不自动转为已确认认知。
- 详细字段、幂等与冲突行为见 [导入协议](../IMPORTS.md)。

## 独立压力验收

本地忽略目录 `.local/revision-02/graph-stress-data` 已生成 800 位虚构人物、1700 段关系和 1 份虚构来源；没有任务或自动化。不会覆盖 `.hither` 或原生个人资料。

浏览器内存夹具由 `src/cognition/graphFixture.ts` 导出，当前默认 `graphFixture` 为 800 人、1578 段关系，`createGraphFixture(count)` 可生成 500 至 1000 人；它与早期隔离数据库中的 1700 关系数量不同。它只在浏览器内存创建对象，不读取、保存或合并个人数据库。现有开发页 `#graph-lab` 使用只读模式，禁用编辑与创建入口，防止示例表单写入当前资料。

在仓库根目录构建当前界面后，可启动隔离环境：

```sh
node .local/revision-02/serve-graph-stress.mjs
```

默认地址为 `http://127.0.0.1:58647/#relationships`。脚本关闭调度器，禁用模型执行。生成脚本为 `.local/revision-02/create-graph-stress.mjs`，允许 500 至 1000 个节点，发现已有数据库时拒绝覆盖。

早期独立 58647 端口被浏览器访问策略阻断，未绕过限制。2026-09-29 晚间改用现有 58644 开发页中的 `#graph-lab`，已完成下述实际浏览器交互；不将早期被阻断的独立端口记为通过。

验收应覆盖：连续缩放与平移、拖拽节点、搜索“人物 400”、邻域聚焦、关系筛选、打开引用、收起详情，以及明暗主题切换。小图与压力图均需检查真实页面；算法预热耗时不能替代帧率或交互验收。

本轮作者已通过 TypeScript 检查和变更格式检查，并确认压力资料数量。独立 Node 合成布局检查中，500 节点约 84 ms、1500 节点约 310 ms，所有坐标有限；该数据仅测布局预热，不是浏览器 FPS。实际画面及交互验收由主代理统一记录。
