# 首次引导与产品介绍

2026-09-30 实现记录。八章围绕了解个人情况、完成一项工作、继续项目和吸收反馈展开；主要工作示例为准备周五的产品体验活动，均为虚构资料。下述内容对应当时的 v3 引导；旧版界面检查不能作为 v3 整套内容或后续版本的验收结论。

| 章节 | 影片内容 | 当前状态与入口 |
| --- | --- | --- |
| 认识 SecondU | 准备周五的体验活动，参考访谈生成文档，把准备时间从三天改为五天并保存 | 开始对话 |
| 了解你 | 从聊天、文件、照片与语音了解个人画像和生活近况，连接时间轴与关系，再用于安排探亲行程 | 个人画像 |

| 找专家帮忙 | 展示研究助手、产品顾问和写作编辑，选择前两位协作整理活动方案 | 助理目录；专家与群聊的真实运行另行验收 |

`ProductGuide.tsx` 管理章节、入口与完成状态；`GuideFilms.tsx` 导出 `GuideShowcaseFilms.tsx`，认知与跨设备场景分别位于 `GuideCognitionFilm.tsx`、`GuideDevicesFilm.tsx`；`filmMotion.tsx` 驱动镜头、输入和光标。影片仅演示交互，不发送消息、发布分身、修改真实日程或调用硬件。标题右侧的“操作演示”／“方案演示”按钮打开说明弹层；设备与能力分享两章使用“方案演示”，其余六章为“操作演示”。影片下方没有旧版的常显“这段体验／当前范围”说明。影片外围为透明背景，产品窗口保留自身表面和圆角。现场图片使用原创生成插画，素材及生成说明保存在 `public/art/guide-device-context-v1.png` 与同名 `.prompt.json`。

动画只循环播放当前章，不自动翻章。认知章为 25.5 秒，其余每章 19 秒；累计可见时长达到一轮后记录完成，跳过、切换与提前关闭不误记完成。当前内容版本为 3，使用 `hither.product-guide.v3`，不继承旧版内容的已看完状态。系统与应用内减少动态效果设置均生效。

9 月 30 日资源占用排查确认：关闭弹窗会卸载当前影片，原有清理会取消动画；但减少动态效果时仍保留逐帧光标测量，隐藏时也未主动取消帧调度。调度修复集中在 `filmMotion.tsx`：隐藏时取消帧与完成计时，并暂停当前舞台内的原生及 CSS 动画；重新可见后从原进度继续。减少动态效果只更新静态画面，并保留一个按可见时长完成的计时器；关闭时移除计时器和监听。调度修复不改视觉内容。虚拟时钟检查覆盖隐藏与恢复、减少动态效果、启动时隐藏与偏好切换、关闭清理；包含静帧开发入口的七项检查通过。这些测试不代表修复后的真实浏览器性能检查。

开发预览支持 `/guide-preview.html?chapter=cognition&at=15500`：章节 ID 从现有章节表校验，时间限制在当前章的 0 至时长减一毫秒。React 内容、打字、光标与原生动画固定同一时间，不运行帧循环，也不触发章节完成。静帧参数只在 DEV 构建的该预览路径生效，普通产品页面和生产构建忽略它；八章继续共用实际组件。

认知章曾出现图谱节点与线条错位。该段已改为单一 `520 × 360` SVG 坐标系，中心人物与四类关系共用节点数据绘制连线，只保留中心到家人、工作伙伴、朋友及社群的四条连接；节点使用 SDK 人物／群组图标，标签向外排列。此次只改图谱，不改资料汇聚、画像或上下文运用段落；整体视觉效果仍需当前版本的页面检查。

光标按当前控件的 DOM 边界定位，箭头尖端与点击圆环使用同一目标。跨设备插画已进行宽屏、英文窄屏和图标尺寸检查，这只覆盖该章的局部改动；八章尚未完成一次覆盖中英文、点击目标和原生包的完整复验。

历史检查曾覆盖旧版工作台剧情、A2A 宽屏交互采样、中英文 390×844 布局、说明区域的宽窄屏呈现，以及 38 次引导点击命中。其后剧情、说明位置与镜头均有改动，这些结果保留为历史范围，不能扩大为 v3 全部通过。
