`ProductGuide.tsx` 管理章节、入口与完成状态；`GuideFilms.tsx` 导出 `GuideShowcaseFilms.tsx`，认知与跨设备场景分别位于 `GuideCognitionFilm.tsx`、`GuideDevicesFilm.tsx`；`filmMotion.tsx` 驱动镜头、输入和光标。影片仅演示交互，不发送消息、发布分身、修改真实日程或调用硬件。标题右侧的“操作演示”／“方案演示”按钮打开说明弹层；设备与能力分享两章使用“方案演示”，其余六章为“操作演示”。影片下方没有旧版的常显“这段体验／当前范围”说明。影片外围为透明背景，产品窗口保留自身表面和圆角。现场图片使用原创生成插画，素材及生成说明保存在 `public/art/guide-device-context-v1.png` 与同名 `.prompt.json`。

动画只循环播放当前章，不自动翻章。认知章为 25.5 秒，其余每章 19 秒；累计可见时长达到一轮后记录完成，跳过、切换与提前关闭不误记完成。当前内容版本为 3，使用 `hither.product-guide.v3`，不继承旧版内容的已看完状态。系统与应用内减少动态效果设置均生效。

9 月 30 日资源占用排查确认：关闭弹窗会卸载当前影片，原有清理会取消动画；但减少动态效果时仍保留逐帧光标测量，隐藏时也未主动取消帧调度。调度修复集中在 `filmMotion.tsx`：隐藏时取消帧与完成计时，并暂停当前舞台内的原生及 CSS 动画；重新可见后从原进度继续。减少动态效果只更新静态画面，并保留一个按可见时长完成的计时器；关闭时移除计时器和监听。调度修复不改视觉内容。无浏览器的虚拟时钟检查覆盖隐藏／恢复、减少动态效果、启动时隐藏与切换偏好、关闭清理；加入静帧开发入口后合计七项通过，记录在 `.local/acceptance/film-motion-20260930/result.json`。为遵守本轮减载要求没有重新启动浏览器，这些检查不代表修复后的实屏性能验收。

开发预览支持 `/guide-preview.html?chapter=cognition&at=15500`：章节 ID 从现有章节表校验，时间限制在当前章的 0 至时长减一毫秒。React 内容、打字、光标与原生动画固定同一时间，不运行帧循环，也不触发章节完成。静帧参数只在 DEV 构建的该预览路径生效，普通产品页面和生产构建忽略它；八章继续共用实际组件。
