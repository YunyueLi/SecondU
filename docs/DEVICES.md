# 设备无关的任务接口预留

本轮只实现桌面与本机运行。此文件定义后续设备接入应遵守的语义，不表示远程设备已经连接。当前本机 API 没有开放到局域网或公网。

`#devices` 另提供[跨端 Dev 交互模拟](DEVICE-SIMULATOR.md)：眼镜输入、桌面草稿与手机确认共享本页内存中的任务修订，可以操作能力限制、离线等待、过期拒绝和去重。它没有真实设备或传输层，不能视为手机、眼镜硬件已经接入。

所有设备引用同一个 `taskId`、认知 `factId/version` 和成果 `artifactId/version`。设备不能复制一份新任务后宣称完成了无缝接续；观察、对话、确认与编辑形成带来源的同一事件序列。

| 设备角色 | 输入 | 主要输出 | 权限 |
| --- | --- | --- | --- |
| 眼镜 | 用户授权的现场观察、语音、带时间的资料候选 | 短语音答复、必要提示 | 采集状态可见；观察只进入来源候选，不自动改正式事实 |
| 手机 | 即时沟通、补充要求、单次确认 | 简短进度、审批、成果摘要 | 确认须绑定确切 taskId、操作、有效期；不继承过期电脑批准 |
| 桌面 | 复杂目标、资料整理、编辑和检查 | 完整任务轨迹、编辑器、认知视图 | 任务工作区受控执行；模型与执行器由用户配置 |

建议后续消息包结构：`{schemaVersion,deviceId,eventId,taskId,occurredAt,kind,payload,sourceIds,expectedVersion}`。`eventId` 用于去重；`expectedVersion` 拒绝覆盖旧成果；设备断线不等于任务已完成。身份配对、端到端传输、密钥轮换与远程节点恢复必须在公开网络接入前单独实现和验收。

二维码代理名片 `hither://agent/v1?data=<base64url-json>` 已在桌面实现。只包含 name、role、instructions、可选 sourceUrl。解析→显示预览→用户确认创建；不自动访问 sourceUrl、不自动执行指令、不包含 API key 或个人背景。手机摄像头和眼镜扫描适配器尚未实现。

Jev 或其他性能优化层预留在执行器适配界面，须先记录当前基线的成本、时间、成功率，再做受控对比；本轮未集成 Jev 或宣称加速收益。
