# 桌面视觉更新验收

2026-09-29。本轮为同一桌面应用的视觉与组件体系更新，使用官方 Apps SDK UI 0.2.2 和虚构演示空间。没有输入密钥、调用外部模型或导入私人资料。

## 实施

- 统一主壳、侧栏、文字尺度、输入区、资料列表、对话、时间轴、人物图谱、成果编辑及设置；移除覆盖官方 Markdown 段落间距的全局规则。
- 新增真实运行的 26 类组件／模式目录，覆盖基础规范 4、输入与选择 8、导航与浮层 5、反馈与状态 5、业务组合 4。支持检索、交互和状态演示。
- 共享 `TaskApproval`、`ArtifactCard`、`SourcePill`；目录与业务页面引用同一实现。产品 tokens 与完整规则见 [DESIGN.md](../../DESIGN.md)。
- 设置拆为个人空间、模型连接、当前电脑、外观、资料；分类切换保留草稿。
- 修复侧栏折叠后的搜索快捷键与开关语义、无效 uniform 属性、成果保存旧响应覆盖新输入、任务提交旧响应清空新草稿；窄窗口成果面板增加焦点约束和背景隔离。

## 本轮实测

| 项目 | 结果与范围 |
|---|---|
| 桌面宽度 | 实际 CSS 视口 900×800、1123×942、1200×800、1440×900；主页／成果面板所测状态无整页横向溢出。截图像素会随浏览器缩放不同，宽度以页面读取值为准。 |
| 明暗主题 | 实际从设置切换浅色／深色，观察主页与任务成果；侧栏、文字、输入区、菜单和页面表面均随主题变化。 |
| 导航 | 收起侧栏后，⌘K 展开并聚焦搜索；来源对话框 Escape 关闭；关系节点选择后详情更新。 |
| 目录 | 分类、检索、菜单按名称选择、来源 Popover、编辑 Dialog、Escape 关闭及触发点焦点返回、审批拒绝后折叠历史、成果展开／编辑切换已操作。不是穷尽所有组合。 |
| 设置 | 临时修改虚构称呼，切换到外观再返回仍保留草稿，然后恢复原称呼，未保存；无密钥时连接测试禁用。 |
| 900px 成果层 | 打开后焦点在关闭按钮，对话区 inert，面板具备 dialog／aria-modal；Escape 关闭后回到原成果入口。 |
| 回归与构建 | 本轮 npm test：40 通过、0 失败、2 个可选真实 Codex 测试跳过；该运行未设置真实执行器测试开关。此前 42 项全通过记录保留在主验收文档。TypeScript 与生产构建通过，存在上游 use client 指令与包体积提示。 |
| 原生启动 | 解锁后退出旧进程，重新打开新版 Hither.app；实际看到新版首页与 26 类组件目录，原有示例任务仍在。 |
| 本机应用包 | 已更新 out/Hither.app；签名严格检查通过，包内 29 个构建文件与当前 dist 哈希一致。旧应用保留在 out/Hither.previous-*。 |
