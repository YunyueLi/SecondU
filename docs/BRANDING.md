# SecondU 品牌与兼容性

2026-09-30，用户明确要求产品统一改名为 **SecondU**，同时更新品牌素材并保留回退。此次只变更产品展示名称，不重新创建用户资料空间。

## 当前品牌

`shared/brand.json` 保存公开名称、字标、图标地址、原生可执行文件名及兼容身份。前端标题和字标、模型身份与原生应用从该配置取名；相关界面、首次引导、工牌、模拟设备和帮助文案同步使用 SecondU。

符号采用两层 U 形线条和一个紫色圆点；字标为本地矢量轮廓，欢迎页继续使用 Pinyon Script 的轮廓动画，文字改为“Hi, SecondU”。Pinyon Script 保留 SIL OFL 许可；字标由本项目绘制几何线条与圆角字形，没有使用现成粗体排字，也不分发系统字体。图形与文字间距同步缩紧。新素材为 `public/brand/secondu-*.svg`、`desktop/assets/secondu.png` 与 `SecondU.icns`。旧素材保留，不以第三方 logo 冒充原创产品标识。

macOS 打包输出为 `out/SecondU.app`，菜单、窗口、可执行文件和图标为 SecondU；只做本机临时签名，不代表 Apple 公证或公开发布。

## 保留的兼容身份

| 项目 | 保留值 | 原因 |
| --- | --- | --- |
| 原生资料目录 | `~/Library/Application Support/Hither/` | 沿用 SQLite、已有任务、浏览器草稿及本机凭据 |
| 开发资料目录 | `.hither/` | 保留现有开发空间及独立示例 |
| Bundle ID | `im.hither.desktop.local` | 避免生成新的应用身份与权限关系 |
| 服务身份、包标记 | `hither-desktop`、`hitherPackaged` | 原生窗口继续复用对应资料目录的本机服务 |
| 环境变量 | `HITHER_*` | 旧的本机启动配置继续可用 |
| 浏览器缓存、IPC、导入协议与内部角色键 | `hither.*`、`hither:*`、`hither.chat.v1`、角色 `hither` 等 | 保留草稿、偏好、名片、导入及任务关系 |

这些值是兼容实现，不是界面品牌。历史对话和用户创建的文件不会被批量改写。历史验收材料仍可能包含旧名称和 `Hither.app`，它们只说明当时版本；应用内开发记录保留这段更名历史。

## 回退

- 最后一次可运行的 `out/Hither.app` 保留为安装包回退；新的打包脚本不覆盖它。后续同名 SecondU 包仍保存带时间戳的前一包。
- 原品牌素材和本次涉及文件的改名前副本在 `branding/legacy-hither/source/`，文件清单与哈希见 `branding/legacy-hither/manifest.json`。备份只含产品源码和素材，不含用户数据、密钥或私人日志，也不会随应用包分发。
- 源码回退使用`branding/legacy-hither/reverse-brand.patch` 更名反向补丁。先检查是否与后续修改冲突，再应用；不要整体覆盖已有的新功能。兼容目录和标识无需迁移或回退。
- 安装包回退需先退出当前版本，再启动保留包，避免同时操作同一资料目录。数据模式新增另按对应迁移规则处理；品牌备份不能替代数据备份。

最终品牌实屏、安装包资源一致性、签名和历史任务保留验证另记本批验收，不能用旧 Hither 包的通过结果替代。
