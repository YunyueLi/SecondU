# Desktop goal

Hither is a personal agent grounded in inspectable, correctable personal cognition. The desktop must connect source evidence to personal understanding, to reasoned task execution, to editable artifacts and feedback. Evidence, inference, confirmed fact and task state are distinct.

Desktop scope: assistant/task workspace, social conversation browser, life timeline, interactive relationship graph with accessible list, self-understanding and active life/goals, evidence import/correction, agent creation and QR profile exchange, collaborative agent roles, local automations, BYOK settings, current computer status, artifact editing/version history, export and actual component catalogue. No dead navigation or fake execution statuses. Native desktop wrapper after browser acceptance. Phone/glasses are documented shared-task protocol interfaces, not implemented hardware.

Visual authority: real official Apps SDK UI controls and CSS/tokens. Neutral ChatGPT composition, generous reading space, restrained sidebar, meaningful typography. Main task surface is an ongoing conversation with inline status and expandable evidence, editable result alongside. Cognition views adapt composition to content, not uniform metric-card walls. All pages use the same controls/tokens including error/loading/empty/keyboard states. Do not recreate the rejected green collage. Synthetic demo content is explicitly labelled. Technical internals belong in settings or expandable activity, not everyday copy.

Execution: local user computer first; configurable Responses providers with DeepSeek as demo configuration, not product lock-in. Codex is the first execution adapter. OpenJarvis contributes modular model/engine/tool/memory/trace/evaluation separation; do not nest two harness loops. Credentials are entered by the user, never copied from their other apps. Until supplied, live model integration remains unverified and the UI truthfully shows configuration needed.

Research continuity: preserve Manus Studio/Cue (editable artifacts, on-demand tools, QR agents), Grok Bot (roles, separate memory and shared work, execution/takeover state), Muse (main relationship, independent tasks, goals/library and reviewable memory), OpenJarvis (local-first runtime modules and quality/cost evaluation). Public behavior cannot prove unpublished internals. Detailed research remains in the user's separate private/local archive; this repo retains public source links and adopted/declined rationale only.

Completion evidence: clean setup, typecheck/build, real persistence and revision-conflict tests, execution adapter protocol tests and installed runtime handshake, source/correction task-context behavior, cancellation/restart/approval honesty, actual desktop browser QA and app launch. Credential-dependent live provider validation is explicitly reported if not possible. No public publishing or private-source migration is implied by local implementation.
