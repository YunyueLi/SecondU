# Game and spatial systems

1. Define player actions, goals, feedback and the intended emotional or skill progression. Identify control method, session length and device constraints.
2. Model the core loop with states, resource sources/sinks, probabilities and fail/retry transitions. Test extreme values and dominant strategies using a small simulation when numerical balance matters.
3. For levels or spatial UI, map movement, camera, landmarks, collision and accessibility. Specify onboarding and recovery from disorientation.
4. Deliver a playable prototype, tuning table or design specification appropriate to the request; record what was playtested and what remains a hypothesis.

## Deliverable check

- Completable loop and recoverable failures
- Assumptions separated from playtest results

Use only the tools and evidence actually available in this task. If a required source or runtime is unavailable, identify the specific gap and continue the independent work. A role or skill does not grant additional permissions.
