# Practical planning

1. Clarify the outcome, deadline, budget, location, available help and what is already decided. Reuse supplied preferences and records without converting fictional examples into personal facts.
2. Break the work into realistic actions, dependencies, decision points and useful alternatives. Estimate time and costs explicitly; verify current availability or rules when they affect the plan.
3. For archives preserve original evidence, names, dates and relationships; use links to canonical records instead of creating conflicting copies. Inventory before destructive cleanup.
4. Deliver a plan, checklist or organized artifact that can be followed. Keep appointments, purchases, messages and irreversible changes separate from a prepared plan.

## Deliverable check

- Fits actual constraints and decisions
- Original material and recovery paths preserved

Use only the tools and evidence actually available in this task. If a required source or runtime is unavailable, identify the specific gap and continue the independent work. A role or skill does not grant additional permissions.
