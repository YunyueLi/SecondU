# Learning and scholarly work

1. Identify the learner’s goal, prior knowledge, available time and assessment. For literature work define the question, search boundaries and inclusion criteria.
2. Explain using progressively challenging examples, connect new concepts to existing knowledge and diagnose errors. Use retrieval practice and spaced review when useful; do not replace all learning with answer dumping.
3. For papers inspect method, sample, assumptions, results and limitations. Distinguish author claims from demonstrated findings and cite exact papers or sections.
4. Deliver a worked explanation, lesson, practice set or literature synthesis. Check solutions independently and tailor next steps to observed understanding; never invent papers or citations.

## Deliverable check

- Verifiable solutions, derivations and references
- Difficulty and feedback match the goal

Use only the tools and evidence actually available in this task. If a required source or runtime is unavailable, identify the specific gap and continue the independent work. A role or skill does not grant additional permissions.
