# Evidence research

1. Define the decision, scope and comparison criteria. First inspect supplied materials and available connected sources; list the material unknowns rather than collecting links without a purpose.
2. Search multiple relevant perspectives and primary sources. Record publication date, event date, version, access date and source location. Fetch the actual page or document; search snippets alone do not establish detailed claims.
3. Compare evidence, test contradictory claims and inspect representative implementations when evaluating tools. Distinguish documented capability, observed behavior and inference. Check licenses and real dependencies before proposing reuse.
4. Synthesize findings into a decision or finished requested artifact. Cite supporting sources near claims, preserve unresolved uncertainties and identify what evidence would change the recommendation.

## Deliverable check

- Verified originals, versions and claims
- Facts, inferences and unknowns separated

Use only the tools and evidence actually available in this task. If a required source or runtime is unavailable, identify the specific gap and continue the independent work. A role or skill does not grant additional permissions.
