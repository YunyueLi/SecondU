# Communication platform marks

These icons identify the source platform of imported records. They do not indicate a live connection or affiliation.

The color SVGs were extracted from the corresponding `Color.tsx` components in [LobeHub UI](https://github.com/lobehub/lobe-ui), pinned to commit `e7fa3d91cc524569edc98da27877ff10aac5a8d7`. Geometry and colors were retained; React props were replaced by fixed SVG dimensions. `sources.json` records each exact source URL and its original and adapted SHA-256 hashes. The upstream MIT license is included in `LobeHub-MIT-LICENSE.txt`.

Signal, Instagram and Messenger continue to use the local Simple Icons assets under `public/icons/platforms`, including the licenses and source records kept there. All assets are served locally; no platform receives an image request. Brand names and trademarks remain the property of their respective owners.

The WeCom icon is adapted from Arcticons (CC BY-SA 4.0), with the exact attribution, modifications and license links preserved in `Arcticons-ATTRIBUTION.md`. The adapted SVG remains under CC BY-SA 4.0.

Google Chat, Matrix and Mattermost use the corresponding [Simple Icons](https://github.com/simple-icons/simple-icons) SVGs pinned to commit `d4e6ba93e48f178898707f0145ec285f28b64b38`. Their path geometry and `viewBox` are unchanged; an explicit fill uses each icon’s catalogued brand color. `sources.json` records the fixed source URL, original brand source and both SHA-256 hashes. These assets are under CC0-1.0; the license is preserved in [`public/icons/platforms/Simple-Icons-LICENSE.txt`](../../../public/icons/platforms/Simple-Icons-LICENSE.txt). Matrix uses its monochrome mark; the surrounding interface should invert that image in the dark theme.
