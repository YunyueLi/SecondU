# Ungetsu moon texture

- File: `ungetsu-moon.webp` (256 × 128 pixels).
- Immediate source: the public mini moon texture used by [ungetsu.net](https://ungetsu.net/), available at [albedo-mini.webp](https://ungetsu.net/scene/directory-moon/albedo-mini.webp).
- Original imagery: [CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/), NASA's Scientific Visualization Studio.
- Credit: NASA's Scientific Visualization Studio.
- This file preserves the original 256 × 128 WebP texture from ungetsu.net byte for byte. No pixels were redrawn, resized or otherwise modified for SecondU.
- The footer displays the texture in a circular element with the same `26% 50%` background position and `200% 100%` background size as the public mini moon.
